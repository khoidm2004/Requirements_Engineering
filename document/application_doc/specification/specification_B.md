# ReadBuddy — Requirements (Version B)

Version B · 2026-10-31

## Introduction

ReadBuddy is a website for kids who have problems with reading, like dyslexia. It should help them get better at reading and make reading fun. Teachers can also use it.

The app should be modern and user-friendly and work on all devices.

## Users

- Kids
- Teachers

## Requirements

1. Teachers must be able to log in.
2. Teachers create a class group with a code.
3. Teachers add students to the class manually with student name + student number.
4. Kids sign in with their student number and name.
5. Teachers can see the kids in their class and their results and assign stuff to them and also add their own texts and upload pictures for sentence–picture exercises.
6. The app should have lots of different reading exercises for different levels, e.g. letters, words, sentences, stories etc.
7. Exercises should be the right difficulty for each kid. The system should figure out the level automatically.
8. Instructions should be clear.
9. The app reads text out loud with a computer voice and should highlight words.
10. Kids should be able to change the font, colours, size and other settings to whatever works best for them.
11. Use a dyslexia-friendly font.
12. When a kid gets an answer wrong the app tells them it's wrong and shows the right answer.
13. Kids can record themselves reading and the recordings are saved so teachers can listen to them later.
14. There should be points and a leaderboard so kids are motivated to practise more.
15. Exercises have a time limit to keep kids focused.
16. Teachers get reports about progress.
17. Shared exercises come with the app.
18. Teachers should be able to export data.
19. Other features may be added later as needed.

## Non-functional requirements

- The app must be fast.
- The app should be secure and protect user data.
- It must follow GDPR.
- All data should be kept so we can analyse it later and improve the app.
- The app should be accessible.
- The app should work 24/7 without downtime.
- The app should handle a lot of users.
